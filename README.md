# SGuard-Tune

一键启动英雄联盟国服客户端（腾讯官方启动器 `Launcher\startup_runner.exe`），并把 ACE 反作弊组件 **SGuard** 的优先级调为「低」、CPU 相关性限制为 **仅 CPU 3**。

> ⚠️ **重要（根因）**：腾讯 ACE 反作弊会在以下情况弹「安全组件运行异常」`(13, 131083, 140)` 并拒绝进游戏：
> 1. **直接用 explorer / PowerShell 拉起 `LeagueClient.exe` 本体**（绕过官方启动链，ACE 不信任该父进程）；
> 2. **以「管理员身份」运行游戏**（被 ACE 判定为环境异常）；
> 3. **改写其受保护进程的优先级/相关性**（本脚本的优化动作，少数情况下会被拦）。
>
> 因此本脚本的策略是：
> 1. 走**腾讯官方启动器（`Launcher\startup_runner.exe`）启动链**——它会拉起 Riot 客户端与游戏本体，ACE 信任该启动链；**不依赖也不使用 WeGame**。
> 2. 启动游戏时**始终以普通用户身份拉起**：即使脚本自身需要管理员权限（改 ACE 进程必须提权），也会先用 explorer 令牌降权再启动客户端，规避第 2 条。
> 3. 脚本自身需要管理员权限，双击后会弹一次 UAC。

---

## 功能特性

- **一键启动 + 优化（默认）**：双击即用。通过腾讯官方启动器 `Launcher\startup_runner.exe` 启动客户端，并对 `SGuard64.exe` / `SGuardSvc64.exe`（国服实际进程名，脚本同时兼容 `SGuard64Svc64` 等写法）：
  - **优先级** 设为「低（Idle）」
  - **相关性** 设为「仅 CPU 3」（掩码 `0x8`；CPU 编号 0 基，即任务管理器里的 CPU 3）
  - **常驻守护**：ACE 每次进游戏都会重新拉起进程或重置设置，脚本每 2 秒巡检一次并自动重新应用；关掉黑窗后已生效的设置仍保留。
- **只启动、不动 ACE（`-NoTune`）**：不提权、不改优先级/相关性、不启用调试特权。

## 环境要求

- Windows 10/11
- PowerShell 5.1（或更高）
- 本机逻辑处理器 ≥ 4（CPU 3 才存在；核心更少时请用 `-Cpu` 指定可用编号）
- **管理员身份**：默认优化模式需要（操作 SYSTEM 级 ACE 进程需 `SeDebugPrivilege`），双击时弹 UAC 授权即可。若只想启动，用 `-NoTune` 则完全不需要管理员。
  - 注意：不要给启动快捷方式勾选「以管理员身份运行」——脚本自己会提权，但它**启动游戏时会自动降权**为普通用户；若快捷方式本身以管理员运行，游戏仍会走降权路径，但不如直接普通双击干净。

## 快速开始

1. 把 `SGuard-Tune.bat`（或 `启动英雄联盟并优化SGuard.bat`）发送到桌面，**普通双击**即可：
   - 弹出 UAC → 点是（脚本需要管理员权限改 ACE 进程）
   - 脚本启动官方启动器拉起客户端，然后等待 SGuard 进程出现，自动设为「低」+「仅 CPU 3」
   - 之后保持黑窗开着即为守护中；关掉窗口则不再巡检（已生效的设置仍保留）
2. 只想启动、不优化：`SGuard-Tune.bat -NoTune`（或 `powershell -File SGuard-Tune.ps1 -NoTune`），不会弹 UAC。

## 命令行参数

直接运行 `SGuard-Tune.ps1` 时可附加以下参数：

| 参数 | 说明 |
| --- | --- |
| `-NoTune` | 只启动客户端，不修改 SGuard（不提权、不启用调试特权） |
| `-NoLaunch` | 不启动客户端，仅对已在运行的 SGuard 做优化/守护 |
| `-Once` | 启动并应用一次设置后退出（不做常驻守护） |
| `-Status` | 仅查看当前 SGuard 进程的优先级与相关性，不做任何修改 |
| `-Cpu <n>` | 相关性绑定的 CPU 编号，默认 `3` |
| `-Priority <name>` | 优先级：`Idle`(默认，即「低」) / `BelowNormal` / `Normal` |
| `-ProcessNames` | 目标进程名列表，默认 `SGuard64, SGuard64Svc64, SGuardSvc64` |
| `-IntervalMs` | 巡检间隔，默认 2000 毫秒 |
| `-WaitSeconds` | 启动后等待 SGuard 出现的上限，默认 300 秒 |
| `-Shortcut` | 手动指定客户端路径（兜底用） |

### 示例

```powershell
.\SGuard-Tune.ps1                      # 默认：启动客户端 + 优化 SGuard（低优先级、仅 CPU 3）
.\SGuard-Tune.ps1 -Cpu 5               # 同一套流程，只把相关性换成 CPU 5
.\SGuard-Tune.ps1 -NoTune              # 只启动客户端，不碰 ACE（不提权）
.\SGuard-Tune.ps1 -NoLaunch            # 客户端已开着，只做优化/守护
.\SGuard-Tune.ps1 -Status              # 只看状态，不改任何东西
```

## 日志

运行日志位于 `%LOCALAPPDATA%\SGuardTune\tune.log`，出问题时查看最快。

## 常见问题

- **报错误码 5（拒绝访问）**：确认已通过 UAC 授权；若已是管理员仍报 5，说明该版本 ACE 开启了自我保护，只能像任务管理器那样手动设置。
- **弹「安全组件运行异常」**：说明本次 ACE 对改写优先级/相关性做了拦截。可先用 `-NoTune` 只启动进游戏，再另开一个管理员 PowerShell 执行 `.\SGuard-Tune.ps1 -NoLaunch` 尝试补设；若仍弹窗，只能放弃优化。
- **CPU 编号越界**：脚本启动时会校验本机逻辑处理器数量并直接报错退出。
