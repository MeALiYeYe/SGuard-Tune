# SGuard-Tune

为腾讯游戏（英雄联盟国服等）提供「一键启动客户端」能力；并可选地对 ACE 反作弊组件 **SGuard** 进程做优先级/相关性优化。

> ⚠️ **重要（根因）**：腾讯 ACE 反作弊会在以下情况弹「安全组件运行异常」`(13, 131083, 140)` 并拒绝进游戏：
> 1. **直接用 explorer / PowerShell 拉起 `LeagueClient.exe` 本体**（绕过官方 Riot 客户端启动链，ACE 不信任该父进程）；
> 2. **以「管理员身份」运行游戏**（被 ACE 判定为环境异常）；
> 3. **以调试特权改写其受保护进程的优先级/相关性**（旧版「优化」所做的操作）。
>
> 因此本脚本【默认】走**官方 Riot Client (`RiotClientServices.exe`) 启动链**——与游戏本体同源、受 ACE 信任，且**始终以普通用户身份拉起**（若被以管理员启动会自动降权）。本脚本**不依赖也不使用 WeGame**。旧版「SGuard 优化」仅作为 `-Tune` 选项保留，但新版 ACE 下大概率仍会被拦截，**不建议使用**。

---

## 功能特性

- **一键启动（默认，安全）**：双击即用，通过官方 Riot Client (`RiotClientServices.exe`) 以普通用户身份拉起游戏——走官方启动链、受 ACE 信任，**不触碰 ACE 进程、不启用调试特权、不触发弹窗**。
- **可选 SGuard 调优（需 `-Tune`）**：把 `SGuard64.exe` / `SGuardSvc64.exe`（国服实际进程名，脚本同时兼容 `SGuard64Svc64` 等写法）的：
  - **优先级** 设为「低（Idle）」
  - **相关性** 设为「仅 CPU 3」（掩码 `0x80`，需本机逻辑处理器 ≥ 4）
  - **常驻守护**：ACE 每次进游戏都会重新拉起进程或重置设置，脚本每 2 秒巡检一次并自动重新应用，关掉黑窗后已生效的设置仍保留。
  - ⚠️ 该模式可能被 ACE 判为篡改安全组件而弹窗拦截，请自行权衡。

## 环境要求

- Windows 10/11
- PowerShell 5.1（或更高）
- 本机逻辑处理器 ≥ 4（CPU 3 才存在；核心更少时请改用 `-Cpu` 指定可用编号）
- **管理员身份**：仅在使用 `-Tune` / `-Status` / `-Once`（需要操作 SYSTEM 级进程 `SeDebugPrivilege`）时才必须；默认的「启动」模式**不需要、也不会请求**管理员权限。请勿给启动快捷方式勾选「以管理员身份运行」，否则游戏会以管理员启动而被 ACE 判为环境异常（脚本会尝试自动降权，但不如直接以普通用户运行稳妥）。

## 快速开始

1. 把 `SGuard-Tune.bat`（或 `启动英雄联盟并优化SGuard.bat`）发送到桌面，**以普通用户身份双击**即可：通过官方 Riot Client 启动客户端。
   （图标可切换为对应游戏的图标，纯属美观；**不要**勾选「以管理员身份运行」。）
2. **默认不优化 SGuard、不提权、不碰 ACE**，因此不会触发 ACE 弹窗，行为等同直接打开官方客户端。
3. 若确需尝试 SGuard 优化（旧版 ACE 下可能有效），在命令行手动执行 `.\SGuard-Tune.ps1 -Tune`，但新版 ACE 下大概率会被拦截，遇到弹窗请去掉该参数。

## 命令行参数

直接运行 `SGuard-Tune.ps1` 时可附加以下参数：

| 参数 | 说明 |
| --- | --- |
| `-Tune` | **启用 SGuard 优先级/相关性优化 + 守护**（默认关闭）。⚠️ 可能触发 ACE「安全组件运行异常」弹窗 |
| `-NoLaunch` | 不启动客户端，仅做调优守护（客户端已开着时用，需配合 `-Tune`） |
| `-Once` | 应用一次设置即退出（不做常驻守护，隐含 `-Tune`） |
| `-Status` | 仅查看当前 SGuard 进程的优先级与相关性，不做任何修改 |
| `-Cpu <n>` | 指定相关性绑定的 CPU 编号，默认 `3`（仅 `-Tune` 时生效） |
| `-Priority <name>` | 指定优先级：`Idle`(默认) / `BelowNormal` / `Normal`（仅 `-Tune` 时生效） |

### 示例

```powershell
.\SGuard-Tune.ps1                     # 仅启动客户端（默认，安全）
.\SGuard-Tune.ps1 -Tune               # 启动并优化 SGuard（可能被 ACE 拦截，慎用）
.\SGuard-Tune.ps1 -Tune -Cpu 3 -NoLaunch   # 客户端已开，只优化
.\SGuard-Tune.ps1 -Status             # 只看状态
```

## 日志

运行日志位于 `%LOCALAPPDATA%\SGuardTune\tune.log`，出问题时查看最快。

## 安全与免责声明

- 默认模式下脚本**通过官方 Riot Client 启动链启动**、**不触碰 ACE 进程、不启用调试特权**，不会触发反作弊拦截（与直接打开官方客户端一致）。
- 腾讯 ACE 会在以下情况弹「安全组件运行异常」`(13, 131083, 140)`：① 直接用 explorer/PowerShell 拉起 `LeagueClient.exe` 本体（绕过官方启动链）；② 以管理员身份运行游戏；③ 改写其受保护进程的优先级/相关性（即旧版 `-Tune` 做的事）。脚本默认已规避这三点；如手动使用 `-Tune` 遇到该弹窗，请去掉 `-Tune`。
- 若 `-Tune` 提权后仍报错误码 5（拒绝访问），说明该版本 ACE 开启了自我保护，只能像任务管理器那样手动设置（脚本日志会给出提示）。
- 本工具仅供个人学习与优化使用，请遵守相关游戏用户协议与当地法律法规。
